API Dokumentation

Der Reportserver stellt neben HTML-Reports auch eine JSON-API bereit. Diese kann von externen Skripten (z. B. Python, Shell) genutzt werden.

Endpunkte

  • /api/mounts → Mountpoints (JSON)
  • /api/logs → Container-Logs (JSON)

Beispiele

Shell (curl + jq)

curl -s http://localhost:8080/api/mounts | jq .
curl -s http://localhost:8080/api/logs | jq .

Python (requests)

import requests

mounts = requests.get("http://localhost:8080/api/mounts").json()
for m in mounts:
    print(m["device"], m["mount"], m["usep"])

logs = requests.get("http://localhost:8080/api/logs").json()
for entry in logs:
    print("Container:", entry["container"])
    print(entry["logs"])

JavaScript (fetch)

fetch("/api/mounts")
  .then(res => res.json())
  .then(data => console.log(data));
